# 06 - Lessons Learned

## Early Lessons Captured So Far

- **Social asset export:** for social media, actual pixel dimensions matter far more than PPI metadata — learned while producing Facebook cover art (see [[02 - Company Naming]])
- **Personal brand first impressions:** pruning distracting late-night/political content from a personal Facebook profile and using a current headshot measurably improves professional first impressions (see [[03 - Networking]])
- **Approachability over polish:** a candid photo (Garden of the Gods) outperformed staged corporate polish for the Zero Down welcome post — personality reads as trustworthy in a community-introduction context
