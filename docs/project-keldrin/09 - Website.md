- **Typography (locked Aug 22, 2026):** Plus Jakarta Sans (display/headings), Inter (body), JetBrains Mono (eyebrows, buttons, contact email, footer, form labels).
- **Page structure:** Nav (small K-mark logo + wordmark) → Hero (photo background) → About (with side visual + network icon row) → How We Work → scroll-photo divider → Who We Help (4 situational cards with Heroicons) → Contact (intro + mailto link + the form, side by side) → Footer.

- **Who We Help cards (settled Aug 22):** charcoal background, hover state `#1E2126`, off-white body text, gold Heroicon + heading, no chip behind the icon.
- **Nav (settled Aug 23, 2026, evening):** now uses the charcoal section color (`.section-charcoal`) instead of slate, so the page doesn't open on a blue-ish band — nav and hero used to both read visually "blue" back to back. Nav is `position: sticky; top: 0` so it stays pinned while scrolling. Added a scroll-triggered flourish (`.nav-sticky.is-scrolled`, toggled by a small scroll listener in `script.js` past a 12px threshold): frosted-glass `backdrop-filter: blur(14px) saturate(140%)`, background dropping to `rgba(22,24,28,0.86)`, a soft drop shadow, and a hairline gold-tinted line (`rgba(229,190,104,0.14)`) along the bottom edge — restrained, not flashy, consistent with the premium charcoal/gold direction. 0.35s ease transition.

## Scroll Motion & Photography — added Aug 25, 2026

**Motion system (`script.js` + `styles.css`):**
- `.reveal` / `.reveal.is-visible` — IntersectionObserver-driven fade + translateY(28px→0) reveal, one-time per element (unobserves after first trigger, so it doesn't replay on scroll-up — deliberately restrained rather than flashy). Applied to: About head/body, Approach head/steps/note, Fit head/cards, Contact intro/form.
- `.reveal-group` — wraps grid children (the 3 steps, the 4 fit-cards) and staggers their transition-delay via `:nth-child` (0/90/180/270ms).
- `.hero-enter` — separate, simpler entrance animation (CSS `@keyframes`, no scroll trigger) for hero content, since it's already in view on load rather than scrolled-to.
- `[data-parallax]` — subtle scroll-linked parallax (rAF-throttled scroll listener, translateY based on `getBoundingClientRect().top * speed`) applied to the hero background photo (speed 0.12) and the scroll-banner photo (speed 0.08). Kept small/restrained on purpose.
- Everything above is wrapped in `@media (prefers-reduced-motion: no-preference)` in CSS and gated by a `matchMedia("(prefers-reduced-motion: reduce)")` check in JS — reduced-motion visitors get all content immediately visible, no animation, no parallax listeners attached.
- Note: elements with the `.reveal` class get a CSS `transform` applied (part of the reveal mechanism), which makes them an `offsetParent` boundary in Chromium — `el.offsetTop` on a descendant returns a value relative to that transformed ancestor, not the page. Doesn't affect real users (mouse-wheel/touch scrolling is unaffected), but tripped up Claude's own Playwright test scripts a couple of times this session. Use `getBoundingClientRect().top + window.scrollY` instead of `.offsetTop` when scripting scroll-position checks against this page going forward.

## Contact Form — status Aug 23, 2026

Both layers fully live in Production:

1. **Storage:** Supabase table `website_contact_submissions` in the `Keldrin OS` project (name, email, message, source, created_at, read). RLS enabled, `anon` role can `INSERT` only. `/api/contact.js` writes to it via Supabase's REST API using the anon key. Honeypot field for basic bot filtering. Kyle reads submissions via the Supabase dashboard Table Editor.
2. **Email notification (Resend):** `/api/contact.js` calls the Resend SDK, gated on `RESEND_API_KEY`. Reads `NOTIFY_FROM` (from-address) and `NOTIFY_EMAIL` (defaults to hopp@keldrin.co).

All four Vercel environment variables are set on the `keldrinco-website` project (Production and Preview): `SUPABASE_URL`, `SUPABASE_ANON_KEY`, `RESEND_API_KEY`, `NOTIFY_FROM`.
