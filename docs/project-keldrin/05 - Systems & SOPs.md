# 05 - Systems & SOPs

## Purpose

Repeatable workflows, operating procedures, checklists, follow-up systems, and automation — the "how we do things" layer that makes Keldrin run consistently as it grows, rather than depending on Kyle remembering every step.

## Relationship to Other Workstreams
