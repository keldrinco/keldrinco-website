# 10 - Legacy Index

## Concept

Legacy Index is the emerging structured relationship/data concept for Keldrin — intended to function as a practical CRM and intelligence system for people, opportunities, specialists, owners, businesses, and deal context. It's the data layer underneath [[11 - Keldrin OS Build]].

## Requirements So Far

- Reduce spreadsheet dependence while preserving structured data
- Relationship CRM is a major requirement: who someone is, what they know, how they can help, what opportunities connect to them, and when/how to follow up (feeds [[03 - Networking]])
- Deal intelligence, field research, owner information, and acquisition pipeline data should eventually live in one coherent system (feeds [[04 - Deals]])
- Three real-world sourcing datasets are defining what this system needs to support — the RV Park, Storage Unit ([[14 - Storage Unit Battle Royale]]), and Mobile Home Park ([[17 - Mobile Home Parks]]) datasets (see [[04 - Deals]])

## Open Decisions

- Legacy Index CRM structure — how it connects people, companies, deals, and follow-ups
- Underlying data model / schema
